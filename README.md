## 📱 Marikina Emergency Application (User Side)

This document contains the **description of each screen** of the Marikina Emergency Application. Each section includes the **file name**, **screen description**, and **main features** based on the provided images.

---

<img width="800" height="1340" alt="Login" src="https://github.com/user-attachments/assets/a53b1464-83cf-46ca-ac8b-f305f3a87cab" />


**Description:**
This is the **Login Page** of the Marikina Emergency Application where users can access the app using their registered email address and password.

**Features:**

* Email Address input field
* Password input field with show/hide option
* **Log In** button
* **Forgot Password** option for users who forgot their password
* **Sign Up Now** option for users who do not yet have an account
* Clean and user-friendly interface for easy access

---

<img width="800" height="1340" alt="SignUp" src="https://github.com/user-attachments/assets/aa874343-af2f-41dd-8d34-52675f8af2ff" />


**Description:**
This is the **Sign Up Page** where new users can create an account in the application.

**Features:**

* Required input fields:

  * Full Name
  * Age
  * Email Address
  * Full Address
  * Contact Number
  * Password
  * Confirm Password
* **All fields are required; submission is not allowed if any field is left blank**
* Email verification process to confirm that the email address belongs to the user
* **Sign Up with Email** button
* Link to the Login page for users who already have an account

<img width="800" height="1340" alt="Profile User" src="https://github.com/user-attachments/assets/5fea9968-493f-46aa-bfb7-f35f3d83ac3e" />


**Description:**
This is the **User Profile Page** where users can view and update their personal information.

**Features:**

* Displays user information such as:

  * Full Name
  * Age
  * Address
  * Email
  * Emergency Contact Number
* Users are **allowed to update their information only once**
* **Save Changes** button
* Displays the user’s **Report History**

<img width="800" height="1340" alt="161 User" src="https://github.com/user-attachments/assets/a383c2a5-d6c2-4d8f-b9de-bb65b7ae2462" />


**Description:**
This is the **161 Rescue Form** used to report emergency situations to Rescue 161.

**Features:**

* Auto-filled user information to reduce manual typing
* Editable address field in case the current location is different
* Disaster type selection
* **Submit Rescue Report** button
* Submitted reports are automatically received by the responders

<img width="800" height="1340" alt="Bfp User" src="https://github.com/user-attachments/assets/3db221c5-32e0-4b6f-908a-a8c738e95862" />


**Description:**
This is the **BFP Emergency Form** used to report fire-related emergencies.

**Features:**

* Auto-filled user information similar to the 161 Rescue Form
* Editable address field
* Hotline selection
* **Call Now** button to directly contact BFP landline for faster response
* **Submit BFP Report** button

<img width="800" height="1340" alt="Report User" src="https://github.com/user-attachments/assets/2bd27338-897b-4231-88a4-34a12a32efa5" />


**Description:**
This is the **History / Report Status Page** where users can track their submitted emergency reports.

**Features:**

* Displays a list of submitted reports
* Shows report details such as:

  * Type of emergency
  * Location
  * Date and time submitted
  * Current responder status (e.g., Pending, On the Way)
* **View in Map** button to track responder location
